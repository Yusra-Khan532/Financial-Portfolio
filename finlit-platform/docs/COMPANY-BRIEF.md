# Company brief (issue 44)

The About section of each company page, written from the company's own filings, every line cited, shown only after a person publishes it.

- Code: `backend/finlit/company_brief/` (core.py pure logic, service.py nightly job, api.py routes), migration `091_company_brief.sql`, `frontend/src/stock/CompanyBrief.tsx`, Console tab "Company brief" (`components/admin/BriefAdmin.tsx`).
- Job `company-brief` (`refresh-company-brief`): needs `GEMINI_API_KEY` (the Ask FinLit AI key; optional `BRIEF_LLM_MODEL`). No key = recorded "not configured", nothing written. Knobs: `BRIEF_MAX_WRITES_PER_NIGHT` (6), `BRIEF_LLM_PER_MINUTE` (4), `BRIEF_LLM_PER_DAY` (60), `BRIEF_TOP_COMPANIES` (500).
- Order: rewrite asked, followed companies (opened in 90 days or active alert), then market cap. Only companies with new filings are rewritten, and only the parts `refresh_plan` names.
- Gates: validate() blocks advice words (buy, sell, reduce, avoid, accumulate, price target, top pick, multibagger...); hold/target/best are flagged for the reviewer, never blocking (they are fine as the company's own words). check() needs every cited string on its cited PDF page. A failed brief is stored as a draft that cannot be published.
- Annual report discovery (no manual work): the nightly job looks each company up in NSE's public annual-reports listing (session-cookie fetch, robots.txt obeyed), then BSE's listing, and stores url, financial year and source (`company_brief_sources.ar_*`). Newest year wins; only https PDFs on the exchanges' own hosts are used; nothing is ever built from a guess. Found = looked up again monthly, none = weekly, blocked/error = daily. The admin URL field is an override and is never replaced. The company's own website is not crawled. **Verified on the live server (7 Nov 2026):** NSE answers the AWS server's address with HTTP 403 (`www.nseindia.com refused the request (403)`) and BSE's robots.txt also answers 403, so every lookup is "blocked" and no brief is written (the same kind of block as AMFI). The same URLs answer 200 from a non-AWS address. Until annual reports can be reached from a non-blocked address, the Gemini key is not used: the job reports `report_blocked` and `llm_left_today` stays at its full value. **Since 7 Nov 2026** the exchange pages are read through the free Cloudflare worker (`deploy/amfi-relay/worker.js`, route `/fetch`, same `AMFI_RELAY_URL` / `AMFI_RELAY_KEY`); **the exchanges refuse Cloudflare's addresses too** (verified 7 Nov 2026: `nseindia.com refused the request (403)` through the relay). So the lookup now first reads the **announcements the site already stores** (`feed_items`, kind `document`, "annual report" in the title or category; they come from the data provider): no request to the exchanges is needed, and the PDFs themselves download from the AWS server (`nsearchives.nseindia.com`, HTTP 200). `ar_source` is `feed`; the run report counts them as `from_feed`. Companies with no stored annual-report announcement still go to the NSE/BSE listings (blocked for now), and a person adding the annual-report URL in the admin override remains the way for those.
- Automatic publication (setting `auto_publish`, default ON, Console toggle, every change audited): a draft with no blocking problem, every citation found on its page (none failed, none unchecked) and no reviewer flag is published with publish_mode 'auto' and the page says "Checked automatically against the filings; every line cites its page." Anything with a flag or failed citation stays a draft for the Console; a brief a person rejected or took down is never auto-published again.
- Budget: `max_writes_per_night` (Console setting, default 6) model calls a night, biggest and followed companies first; when the cap is hit the run keeps doing cheap annual-report lookups, so the whole market fills over nights.
- Public: `GET /api/stocks/{symbol}/brief` (published copy only, re-validated on every read, otherwise a reasoned empty state). Admin: `/api/admin/company-brief/*`.
- The Reliance prototype lives only in `backend/tests/fixtures/company_brief/` and `frontend/src/lib/fixtures/`; never loaded into production.
