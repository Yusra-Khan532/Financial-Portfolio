# AI share-of-voice panel (workstream M9)

*Run once a month, with the same 60 questions in the same 7 places, so the months compare. The first run is the baseline: where FinLit starts. Takes about 1 hour by hand.*

## How to run it
1. Use a **private/incognito window**, signed out where possible, so answers aren't personalised. Note the date.
2. Ask each question, word for word, in each place:
   1. Google AI Overview (google.co.in search)
   2. Google AI Mode
   3. ChatGPT (with search)
   4. Gemini
   5. Claude (with web search)
   6. Perplexity
   7. Microsoft Copilot
3. For each answer, fill in one row of the month's log (below):
   - **Named:** is FinLit named? (Y/N)
   - **Position:** if it's named, where it sits in the list (1 = first)
   - **Cited:** is a finlitventures.com page linked as a source? (Y/N)
   - **Competitors named:** in the order the answer gives them
   - **Outside pages cited:** the URLs. These become the **M4 outreach list**.
4. Don't count an answer that names a *different* FinLit (UK/US financial-literacy groups). Write "other FinLit" in the notes instead.
